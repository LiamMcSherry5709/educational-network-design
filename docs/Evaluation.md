## Justifications of hardware and software devices 
The first area I would like to evaluate is the justifications for choosing to use the different network hardware and software devices. The network that we have designs contains a variety of different devices, most of these devices are located on the ground floor, in contrast the first and second floor have a similar topology and the same device types. The ground floor contains PCs, servers, printers, wireless access point, router, firewall, and 4 switches. The first and second floor only contain PCs. The ground floor is separated into 2 device hubs the main ground floor itself and the security room, i will discuss the security room more later. The justification for my choice of placing most of the network hardware on the ground floor is primarily to aid in troubleshooting as if a problem occurs were the network fails the administration will not have to speculate on the geographical location of the issue for long as it would be safe to assume that the source of the problem is located in the area containing all devices that help support the networks function. 
Moving on for the justification of the layout of the network devices, I will now make my justification for the inclusion of the induvial device types. One question may pertain to inclusion of devices such as the wireless access point. Well, I choose to include a wireless access point because it will provide scalability for the network regarding wireless devices such as mobile phones and laptops, having these devices be supported by the network will the network more accessible to all users as most people have some form of wireless device. Other users may inquire about why I choose a specific server. For the network I choose to implement a combination server and my justification for doing so is because the combination server can provide the services of many different types of servers such as file servers, print servers, and DHCP servers. This is important for my network because of the many roles and requirements the users have. For example, one student may wish to print out some work to hand to their teacher. So, for this they would need a print server, but another student may wish to send the file directly to the teacher. And for this they would need a file server. Rather than having both a print server and a file server, having just one combination server would allow for both these services to be fulfilled.
The considering the PCs or workstations there are also many question that may be asked, most of them related to the software and hardware that will support the workstation. Software such as the PCs operating system may be brought into question as they are many choices to choose from all with their own benefits and drawbacks. OSs such as Windows, mac, or Linux. Are all viable options but for the purposes of my network I have chosen Windows, my justification for doing so is because Windows is the Operating system users will be familiar with and compared to other operating systems like linux which can have somewhat of a learning curve for users when first using it, Windows is very straight forward and easy to operate which for my network suits perfectly as it accommodates users that have varying range of technical savvy. Another question that may be posed is what connection method will i use to connect the workstations to the network? Will it be cabled or wireless? For my network i have chosen a cabled connection. Now despite having access to a wireless access point a wired connection is required for these devices as desktop PC is used to perform much large computational tasks than devices such as mobile phones and laptops, so a connection which provides better stability is required and this is done through using a wired connection such as ethernet cables. The PCs to their name's sake are desk bound so the one benefit of a wireless connection being the ability to access the network remotely while on the go would be lost on these devices.
Another very important device to consider is the router. The router is what allows for the transmission of data across the network's backbone. So, for this reason, a router is needed to support the network without question. But something users might notice is the inclusion of a fire wall assigned to the router. And they may ask why the router why not the server or wireless access point or printer. Well, the router as well as being responsible for transmitting data it is also the main line of communication with the greater internet. The router can take data packets from the internet and send them around the devices on the network. For example, a workstation may want to access a certain web page, well to do so the workstation would send a HTTP request to the web server through the router and in return the webserver would send the Workstation the webpage again through the router. Now, this is not a fool proof system as the router can be main access for malicious data packets containing malware to enter the organisations LAN. To prevent this from happening a firewall is set up to monitor the traffic trying to enter the network through the router and deny access to any data packets that it has identified as being dangerous. This is why need a fire wall and why it is placed alongside the network.

Another device that is just as important as the router in connecting the network is the switch, or in the case of my network switches. A simple question regarding switches is just why do we need them? The switch's function is connecting all the devices together allowing for data to be transmitted through the connections. A switch has many different ports; these ports allow for cables to be inserted in them that will establish a connection with the device on the other end. This connection doesn't just apply to the device and the switch but all the other device which happen to be connected to the switch also are connected to one another. 
What connects the devices together through the previously mentioned switches is the cabling. And when deciding what cabling to choose there is no shortage of options. From Shielded to unshielded, thick coaxial to ethernet, there are plenty of choices but for my network I have chosen the unshielded twisted pair category 6 cables. This cable type is suitable for 10BASE-T all the way to 1000BASE-T gigabit ethernet connections. This mean this cable standard is suitable to handle the requirements of the network. The UTP cables are the most common type of cable chosen for computer networks as they are more inexpensive then the STP cables.

The only device which I haven't provide any justification for yet is the printer. Depending on the requirements from the network users' printers may or may not be needed but in the case of my network they are needed, seeing as my network is made to support an educational institution it is only natural that a lot of documentation, reports, essays, diagrams etc will need to be printed into a physical format. For these requirements to be met I believe that one printer won't cut it and that three printers are required due to scenario that network is placed in. For example, many students may need to print out their end of year assignments, if only one printer is available not only will the que for it be extremely long, but it also may run out of paper or ink before all the students have printed their assignments. To prevent situations like this from happening multiple printers must be included on the network. Something that also must be taking into consideration what type of ink will it use, coloured or black and white. The printer on my network will use black and white as most what’s being printed will be formal documentation, so colour isn't required for the most part. The manufacturer must also be taken into consideration. The printers on my network will be HP printers as they are not too expensive while being of high enough quality to fulfil their purpose and not require much maintenance or replacing. 

I have provided justification for all the devices, now I must provide justification for the different security measures taking to ensure that the network remains secure and is able to function even with extenuating circumstances effecting it. 

## Security 
At the beginning of this evaluation, I mentioned the security room on the ground floor. Now, one question some may have, is why we even need a security room. Well, the reason I have chosen the implement a security room into the network is because the devices that are stored within it are not only vital to the networks function but also, they are very expensive. Putting these devices in a room that is inaccessible to unauthorised personnel greatly reduces the likelihood of them being stolen or destroyed, this is in the organisations best interests to save money and have the network continue to function. 
Other security measures that may be brought into question is the different software that is installed on the devices. Software such as anti-virus and anti-spyware are installed onto the workstations and server. Users may wonder why especially if certain activities they are trying to perform are impeded by this software. Well without this software in place the network is much more likely to pick up viruses and malware that allows hackers intercept and steal the data that is contained within the network. These viruses and malware can be picked up by users of the network through their internet activities. The anti-virus and anti-spyware software will prevent this as they contain list of known viruses and malware that they are able to identify and restrict access to by informing the users that they are at risk or just by directly eliminating they form the device. For this reason, I believe that installing anti-virus and anti-spyware software on all the network devices is justified. 
Another aspect of security that may be brought into question are data backups more specifically how often data backups are updated. On my network data backups are made every night on the server. This is done so that in the case of data being lost their will always be up to date backups that data.

## Quality of service 
The final area of justification that I will covers is justifying the quality of services for selection of accessories. This encompasses aspects like the technical support and staff, the quality of the devices to support the network, bandwidth requirements being met, and staff access to certain devices. 
Firstly, the technical staff are vital to ensure that the network remains up and running through identifying issues and correcting them and ensuring that the network is configured correctly. Due to their importance the question may arise asking how much support there is to manage the network. In the network I have create the technical staff consists of three computer network administrators, The justification for this decision is because the network consists of three LANs, one on each floor. So, each network administrator could oversee their own floor. This would help spread the workload and mean the admins don't get overwhelmed.
I have already spoken about the justification for the inclusion of certain network devices. But I haven’t yet justified the standards of quality which is enforced onto these devices. For example, when reviewing the network, the question of the quantity of certain devices may be brought into question, e.g. are there enough switches to accommodate all the devices on the network. By reviewing the design, I have concluded that four switches are required to accommodate the current number of users on the network. Two of these switches are used to connected only the devices on the ground floor as that floor contains the most devices. Another quality concern many be, does the server contain adequate CPU, RAM, and disk storage to support the network? The main services that the server will provide on the network is file sharing and fulfilling print request, for this purpose the server has an adequate amount of the variables listed to provide these services. 
Bandwidth is another concern for the network as if the organisation does not have enough, it will affect the networks performance negatively. So, it is important that we ask ourselves do we have enough bandwidth not just to support the current users base but for future additional users as well. The bandwidth that we have been provided is from BT and not only were the correct bandwidth calculations done to determine the exact amount required to support the networks current peak activity but also to identify the right amount of padding needed to support future growth. Additionally, the choice of cable being the UTP category 6 is used to better utilise the increased bandwidth.
